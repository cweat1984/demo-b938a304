Southern Command – TEST BUILD (source version a120818, built Nov 13, 2026)

This is a test copy for trying out the app. It is not the live site and holds no real company data.

How to open:
- From a link: open the test link and type the same password you use for the live Southern Command demo.
- From this download: unpack the whole folder (keep images, icons, sds and manifest next to index.html),
  open index.html in Chrome or Edge, and type the same password.

Good to know:
- Anything you enter is saved only in that browser on that device. It is not shared, synced or backed up.
- If you use the live site's full "clear / reset data" while both are on the same web address,
  it can also reset this test copy. The test copy cannot reset the live site.
- Do not enter real employee information.
